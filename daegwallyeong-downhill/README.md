# 대관령 다운힐: 씨티백 레전드

> 아무리 좋은 바이크를 타도, 씨티백 탄 할배는 못 이긴다.

실제 **대관령 옛길(경강로·지방도 456호선, 대관령 정상 → 강릉 성산 12.5 km)** 을 위에서 내려다보며 달리는 **도트 그래픽 코믹 다운힐 레이싱** 웹 게임입니다.
한 판은 45~75초짜리 단판 승부. 내 바이크는 처음부터 꽤 좋고 개조할수록 괴물이 되지만, 상대는 8마력 씨티백을 **한 손으로, 무릎으로, 발로, 심지어 강아지에게 맡기고** 타는 고인물 "황 영감"입니다. 할배는 달리는 내내 떠듭니다.

- 이미지·모델·음원 파일 없이 **코드만으로** 그리고 소리 냅니다 (Canvas 2D 도트 렌더링 + Web Audio 합성음). 외부 파일은 도트 글꼴 하나뿐이고, 그것도 `index.html` 안에 들어 있습니다.
- 지도는 **실제 데이터**입니다: 도로 선형, 고도, 토지피복, 건물 외곽선, 하천, 풍력발전기, 버스정류장까지 도트로 찍어 냅니다.
- `index.html` 한 파일로 실행됩니다 (서버·설치 불필요, 약 0.9 MB). 가로·세로 화면 모두 됩니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 정적 호스팅(GitHub Pages 등)에 그 파일 하나만 올려도 됩니다.

| 조작 | 키보드 | 터치 | 게임패드 |
| --- | --- | --- | --- |
| 기울이기 | ← → / A D | 왼쪽 패드를 좌우로 밀기 | 왼쪽 스틱 |
| 브레이크 | ↓ / S / 스페이스 | BRAKE 버튼 | LT · B · X |
| 니트로 | Shift / X | N2O 버튼 | A · RB |
| 일시정지 | P / Esc | II | Start |

가속은 자동입니다. 화면은 돌지 않고 바이크가 돕니다. **좌우는 화면이 아니라 바이크 기준**입니다 (왼쪽 키 = 바이크의 왼쪽).
코너 앞에서 미리 줄이고, 들어가서는 브레이크를 놓으세요. 브레이크를 잡은 채로는 바이크가 덜 눕습니다.

## 게임 구조

- **레벨 10개** = 실제 코스의 구간. 굽이가 완만한 구간(성산 진입로)부터 가장 심한 구간(해발 720→600 m 연속 굽이) 순서이고, 마지막은 12.4 km 풀코스 결전입니다. 레벨이 오르면 날씨(단풍·노을·안개·밤·비)와 장애물(낙석·고라니·경운기)도 붙습니다.
- **통과**: 할배와 정해진 초 이내로 완주하면 별 둘로 다음 레벨이 열립니다 (LEVEL UP). 이기면 별 셋.
- **개조**: 엔진·타이어·브레이크·서스펜션·경량화(각 5단계), 니트로(3회), 그리고 성능 +0짜리 LED 언더글로우와 "할배 조심" 스티커.
- **멘탈 하트 5칸**: 넘어지거나 추월당하면 한 칸씩 깨집니다. 남은 하트만큼 상금이 붙습니다.

### 할배의 핸디캡

할배는 판마다 스스로 핸디캡을 겁니다. 실제 속도와는 무관한 **연출**이고, 화면의 "할배 진심도" 게이지는 평소 20%를 넘지 않습니다.

| 레벨 | 핸디캡 | 레벨 | 핸디캡 |
| --- | --- | --- | --- |
| 1 | 한 손 운전 + 믹스커피 | 6 | 수면 안대 + 신문 |
| 2 | 양손 철가방 (무릎 운전) | 7 | 강아지 감자가 운전, 할배는 뒤돌아 구경 |
| 3 | 10 m 계란판 탑 | 8 | 한 손 우산, 한 손 전화 |
| 4 | 뒤로 돌아앉아 운전 | 9 | 짐 10 m + 발 운전 + 낮잠 |
| 5 | 누워서 발로 운전 | 10 | 아홉 가지 전부를 구간마다 교체, 마지막 2 km만 두 손으로 |

- 앞서면 딴짓을 하며 기다리고(커피를 한 잔 더 탄다, 계란을 한 판 더 얹는다…), 뒤처지면 핸디캡을 하나만 풀고 따라붙습니다. 마지막 16% 구간은 봐주기 없이 달립니다.
- **트래시토크**: 4~6초마다 한 마디, 사건(넘어짐·긁힘·긴 브레이크·니트로·추월)이 나면 바로 한 마디. 대사는 300여 줄이고 놀리는 대상은 비싼 바이크와 운전 실력뿐입니다 (욕설, 외모·가족 비하 없음 — `npm test`가 금칙어를 검사).
- 황 영감과 강아지 감자는 가상의 캐릭터입니다.

## 도트 그래픽

- 화면은 낮은 해상도 캔버스(짧은 변 약 230~290칸)를 **화면 픽셀의 정수 배**로만 키웁니다. 도트 한 칸 = 실제 0.25 m.
- 바닥은 128칸짜리 조각으로 미리 찍어 둡니다: 토지피복 색 × 실제 고도의 언덕 음영(디더링), 그 위에 하천·샛길·건물·도로·가드레일·나무.
- 바이크와 할배는 복셀을 층층이 쌓아 그리는 "스프라이트 스택"이라, 위에서 본 화면에서도 바이크가 눕고 계란탑이 휘청댑니다.
- 화면 방향은 레벨마다 고정(출발 → 도착이 위쪽)이고 돌리지 않습니다. 도트가 뭉개지지 않게 하기 위해서입니다.
- UI 글꼴은 [갈무리11](https://github.com/quiple/galmuri)(SIL OFL 1.1)을 쓰는 글자만 추려 넣었고, 글자 크기는 항상 11px의 정수 배입니다.
- 이전의 3D(three.js) 버전은 커밋 `ebb31f9`에 남아 있습니다.

## 실제 지도 데이터

| 항목 | 내용 | 출처 |
| --- | --- | --- |
| 도로 선형 | 507개 좌표, 수평 길이 12,511.246 m. 기획안에 기록된 좌표 배열 SHA-256 `18f412f8…75b4`와 일치 | © OpenStreetMap contributors (ODbL), Overture Maps 2026-10-21.0 경유 |
| 고도 | 출발 843 m → 도착 72 m. 코스 주변 12.5 m 격자 + 동해안까지 125 m 격자 | Mapzen/Tilezen Terrain Tiles (AWS Open Data, SRTM 등 합성) |
| 토지피복 | 숲·관목·경작지·시가지·나지 (25 m 래스터) | ESA WorldCover (CC BY 4.0), Overture 경유 |
| 건물 59동, 샛길 128개, 하천 17개, 풍력발전기 21기, 송전탑 44기, 버스정류장 8곳, 교량 2곳 | 실제 위치·외곽선 | Overture Maps (OSM·기타 공개 자료) |

도로는 원본 정점을 모두 지나는 곡선으로 잇고 꺾임만 다듬었습니다. 코너를 지우거나 다시 그리지 않았습니다.
게임 중심선과 원본 폴리라인의 편차는 **평균 0.13 m, 최대 2.08 m** 입니다 (`npm test`가 매번 확인).

데이터를 다시 받으려면 `tools/`의 파이썬 스크립트를 순서대로 실행합니다 (`pyarrow`, `numpy`, `pillow`, `requests` 필요).

```bash
python3 tools/fetch_overture.py transportation segment 128.72 37.65 128.87 37.75 raw/segments.json
python3 tools/build_course.py raw/segments.json raw/course_path.json   # 507점·길이·해시 대조 출력
python3 tools/fetch_dem.py raw/course_path.json raw/dem
python3 tools/build_features.py raw data                               # 건물·하천 등 (나머지 레이어도 fetch_overture로 받아 둔 뒤)
```

## 구글 지도 연동

| 기능 | 키 필요 | 상태 |
| --- | --- | --- |
| 코스 선택 화면의 "스트리트뷰 ↗" (공식 Maps URL, 새 창) | 아니오 | 링크 형식 테스트로 확인 |
| "구글 지도 미리보기" (위성지도 임베드) | 아니오 | 임베드 주소 구성만 확인. 호스팅 환경의 프레임 정책에 따라 막힐 수 있음 |
| **위성사진 도트 바닥**: Map Tiles API 위성 타일을 받아 색 단계를 줄여(디더링) 도트 바닥으로 깖 | 예 (Map Tiles API) | 요청 형식·모자이크·좌표 정합은 모의 타일로 검증(`npm run test:sat`). **실제 구글 서버 응답은 키가 없어 미검증** |
| 코스 선택 화면 안 스트리트뷰 (Maps Embed API) | 예 | 미검증 |

키는 게임의 **설정 화면에 직접 입력**하며 그 브라우저의 localStorage에만 저장됩니다. 저장소·빌드 결과물에는 키를 넣지 않습니다.
키가 없거나 요청이 실패하면 자동으로 "실제 고도 + 토지피복 색" 바닥으로 돌아갑니다.

## 개발

```bash
npm install          # esbuild, galmuri(글꼴 원본)
npm run build        # src/ + data/ → index.html (한 파일)
npm test             # 데이터·물리·대사 검증 + 헤드리스 브라우저 스모크 테스트
npm run test:sat     # 구글 위성 타일 경로 모의 검증
npm run test:full    # 한 판을 끝까지 달려 결과·저장까지 확인 (4배속, 약 20초)
npm run sim          # 봇이 실제 게임 물리로 전 레벨을 달려 할배와의 격차를 표로 출력
npm run calibrate    # 레벨별 할배 페이스(k) 재보정
python3 tools/subset_font.py   # 대사·UI 문구를 고친 뒤 글꼴 다시 추리기 (fonttools, brotli)
```

주소 뒤에 `?stage=3&auto=1`을 붙이면 봇이 대신 달립니다 (`&skill=0.9`, 시험용 배속 `&speed=4`).

| 파일 | 역할 |
| --- | --- |
| `src/track.js` | 실제 좌표 → 주행 중심선, 곡률·고도·노폭, 레이싱 라인, 속도 프로파일 |
| `src/physics.js` | 플레이어 바이크 (기울기 → 선회율, 마찰원, 가드레일 접촉) |
| `src/rival.js` | 할배 AI (레이싱 라인 추종, 딴짓·따라붙기, 추월 회피, 풀코스 메들리) |
| `src/talk.js` | 핸디캡 정의, 대사, 상황별로 대사를 고르는 연출 |
| `src/game.js` | 레이스 진행, 카메라, 장애물, 이펙트, 날씨, 화면 그리기 |
| `src/px/world.js` | 실제 지도 → 도트 바닥 조각 (지형·도로·건물·나무·소품) |
| `src/px/vox.js` | 스프라이트 스택 모델 (내 바이크, 할배와 핸디캡 10종, 장애물) |
| `src/px/sky.js` · `sprites.js` · `text.js` · `palette.js` | 메뉴 배경(실제 능선 실루엣), 도트 소품·아이콘, 도트 글자, 팔레트 |
| `src/hud.js` · `src/ui.js` | 주행 화면 표시 / 메뉴·차고·결과 화면 |
| `src/audio.js` | 엔진·씨티백 "탈탈탈"·뽕짝 라디오 등 합성음 |
| `src/google.js` | 구글 지도 연동 |
| `src/config.js` | 레벨·개조·날씨·밸런스 값 |

## 밸런스에 대해

레벨별 할배 페이스는 "권장 개조 수준의 바이크를 탄 봇이 이론 최속의 약 88~92% 로 달리면 비긴다"에 맞춰 자동 보정했습니다 (`tools/calibrate.mjs`). 핸디캡은 연출이라 페이스에 영향을 주지 않습니다.
다만 **사람이 직접 플레이한 검증은 아직 없습니다.** 체감 난이도는 설정의 "할배 실력"과 `src/config.js`의 `k` 값으로 조정하세요.

## 알려진 한계

- **사람이 직접 플레이한 검증은 아직 없습니다.** 조작감·난이도·대사 빈도는 봇 주행과 화면 캡처로만 확인했습니다.
- 고도는 30 m급 공개 DEM을 도로 방향으로 평활화한 값입니다. 현장 측량 종단과 다를 수 있습니다.
- 게임 속 노폭은 도트 화면에서 추월할 자리가 나도록 실제보다 넓게(약 10 m, 급코너 확폭) 잡았습니다. 가드레일·옹벽 위치는 지형 기울기에서 추정한 연출입니다.
- 건물 높이·색, 나무 위치는 추정입니다. 실제 사업체 간판은 넣지 않았고 공공 지점(박물관·기념비·정류장)만 표시합니다.
- 실행은 헤드리스 크로미움으로만 확인했습니다 (1080p와 휴대폰 크기 모두 프레임당 그리기 2 ms 미만). 실제 기기에서의 성능과 소리는 확인하지 못했습니다.
- 게임 속 주행은 차량이 없는 가상 통제 코스 설정입니다. 실제 도로에서는 안전 운전하세요.
